MY ACCOUNTS PRO — مشروع إنشاء APK تلقائيًا

هذا الملف يحتوي مشروع Android Studio، ومعه GitHub Actions لبناء ملف APK تلقائيًا من GitHub.
تنبيه: الملف الذي تحمّله هو مشروع البناء، وليس APK جاهزًا. بعد تشغيل الخطوات التالية سيظهر APK للتنزيل.

طريقة البناء من الموبايل أو الكمبيوتر:

1) فك ضغط ملف MyAccountsAPK_AutoBuild.zip.
2) افتح github.com وسجّل الدخول، ثم أنشئ مستودعًا جديدًا (New repository).
   يمكنك تسميته: my-accounts-apk
3) ارفع جميع محتويات المجلد إلى المستودع، وليس ملف ZIP نفسه.
   مهم: ارفع مجلد .github أيضًا؛ قد يكون مخفيًا في مدير الملفات، فعّل إظهار الملفات المخفية إذا لم يظهر.
4) بعد اكتمال الرفع افتح تبويب Actions في المستودع.
5) اختر workflow باسم Build MY ACCOUNTS APK.
6) اضغط Run workflow ثم اضغط زر Run workflow الأخضر للتأكيد.
7) انتظر حتى تنتهي العملية وتظهر علامة نجاح خضراء.
8) افتح نتيجة التشغيل، وانزل إلى قسم Artifacts.
9) حمّل my-accounts-pro-apk.zip وفك ضغطه؛ ستجد بداخله app-debug.apk.

تثبيت التطبيق:
- انقل app-debug.apk إلى هاتف Android.
- افتحه واسمح بالتثبيت من هذا المصدر إذا طلب الهاتف ذلك.
- هذه نسخة Debug للاستخدام والتجربة، وليست نسخة منشورة على Google Play.

ملاحظات:
- يحتاج تشغيل البناء إلى اتصال إنترنت وحساب GitHub.
- لا تحذف مجلد .github/workflows لأنه المسؤول عن تشغيل البناء التلقائي.
- بيانات التطبيق محفوظة محليًا على الهاتف باستخدام تخزين المتصفح (Local Storage). لا تمسح بيانات التطبيق أو مساحة التخزين الخاصة به حتى لا تفقد البيانات.
- يُفضّل الاحتفاظ بنسخة احتياطية من بياناتك بانتظام إن كانت خاصية النسخ الاحتياطي متاحة داخل صفحة الحسابات.

معلومات المشروع:
- اسم التطبيق: MY ACCOUNTS
- Android package: com.myaccounts.app
- الحد الأدنى: Android 6.0 (API 23)
